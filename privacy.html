プライバシーポリシー

KAKKO26 YouTube運営（以下「本ツール」）は、運営者本人が自分の YouTube チャンネルを管理するための個人用ツールです。

取得する情報

Google アカウントの許可（OAuth）により、運営者本人の YouTube チャンネルについて、動画のアップロード・公開設定・再生リストの編集と、YouTube Analytics の統計（再生数・視聴時間など）を扱います。

使い方

取得した情報は、運営者本人の動画の公開作業と、どの動画がよく見られたかの分析にだけ使います。

保存と第三者への提供

許可の記録と統計は運営者の手元のコンピューターにだけ保存します。第三者への提供・販売はしません。

本ツールによる Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消し

許可は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。
